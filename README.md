# Software development and architecture.

Este repositório tem como objetivo instruir o estudante em um caminho para sua trajetória dentro da área de desenvolvimento de software. Foram incluídas diversas fontes de conteúdo, passando por tópicos importantes, desde o básico, como lógica de programação, até níveis mais avançados, como engenharia e arquitetura de software em camadas, DevOps e conteúdos em CI/CD e deploy.
